# 📊 Sales & Profit Analysis Dashboard (Power BI)

## 🧾 Project Overview
This project presents an end-to-end Sales and Profit Analysis Dashboard built using Power BI. The dashboard provides deep insights into business performance across markets, customers, products, and time.

It helps stakeholders understand:
- Where revenue is generated  
- Which markets are profitable  
- Which areas need improvement  
- How performance changes over time  

---

## 🎯 Business Problem
The company generates high revenue but lacks visibility into:
- Profitability across different markets  
- Contribution of customers and products  
- Underperforming regions  
- Year-over-Year performance trends  

This dashboard solves these problems by providing interactive and data-driven insights.

---

## 🛠️ Tools & Technologies Used

- Data Modeling  
- Data Visualization

## 🔍 Key Insights

- Delhi NCR contributes the highest revenue but has low profit margin → indicates inefficiency  
- Bhubaneswar has high profit margin but low contribution → growth opportunity  
- Lucknow shows negative profit margin → loss-making region  
- Revenue is concentrated in a few markets → business risk  
- Brick & Mortar dominates sales → E-commerce has growth potential  

---

## 🚀 Business Recommendations

- Improve margins in high-revenue markets (e.g., Delhi NCR)  
- Scale high-margin markets (e.g., Bhubaneswar)  
- Re-evaluate or optimize loss-making regions (e.g., Lucknow)  
- Expand E-commerce channel  
- Focus on high-value customers  
- Diversify revenue across markets  

---

## 🧠 Key Learnings

- Understanding difference between Profit Margin vs Profit Contribution  
- Creating interactive dashboards using Power BI  
- Using DAX for advanced calculations  
- Converting data into actionable business insights  

---

## 📌 Conclusion
The dashboard highlights that while the business generates strong revenue, profitability is uneven across markets. By focusing on improving efficiency and scaling high-potential regions, the company can enhance overall performance.
